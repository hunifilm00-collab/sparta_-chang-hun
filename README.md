# 작심삼일

할 일과 마감일을 적으면 마감까지 날짜별로 나눠 달력에 정리해 주고, 밀린 일은 날짜를 옮기거나 쪼개서 다시 나눠 주는 일정 도구입니다. 서버와 로그인 없이 브라우저에서만 동작합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 빌드가 필요 없습니다.

## 검증

```
node scheduler.test.js
```

계산 로직의 검증 사례 40개를 확인합니다.

## 구성

- `index.html`: 화면 뼈대
- `style.css`: 스타일
- `scheduler.js`: 계산 로직
- `app.js`: 화면 동작과 저장
- `fonts/`: 연성(Yeon Sung) 글꼴에서 필요한 글자만 줄인 파일과 라이선스 문서
- `scheduler.test.js`: 계산 검증

## 배포

저장소의 루트에 이 폴더의 파일을 그대로 올리고, Vercel에서 저장소를 가져오면 `index.html`이 열립니다. 별도 설정은 필요 없습니다.

## 저장

입력한 내용은 브라우저의 localStorage(`jaksim.v2`)에만 저장됩니다. 서버로 보내지 않습니다.

## 글꼴

서비스 이름과 화면 제목에 연성(BM YEONSUNG) 글꼴을 씁니다. SIL Open Font License 1.1로 배포되는 글꼴이며, 라이선스 문서는 `fonts/OFL.txt`에 있습니다. 외부 서버에서 불러오지 않고 이 저장소의 파일만 씁니다.
