# 작심삼일

밀린 일을 지금 가능한 시간에 맞춰 다시 짜 주는 일정 도구입니다. 서버와 로그인 없이 브라우저에서만 동작합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 빌드가 필요 없습니다.

## 검증

```
node scheduler.test.js
```

계산 로직의 검증 사례 26개를 확인합니다.

## 구성

- `index.html`: 화면 뼈대
- `style.css`: 스타일
- `scheduler.js`: 계산 로직
- `app.js`: 화면 동작과 저장
- `scheduler.test.js`: 계산 검증

## 배포

저장소의 루트에 이 폴더의 파일을 그대로 올리고, Vercel에서 저장소를 가져오면 `index.html`이 열립니다. 별도 설정은 필요 없습니다.

## 저장

입력한 내용은 브라우저의 localStorage(`jaksim.v1`)에만 저장됩니다. 서버로 보내지 않습니다.
